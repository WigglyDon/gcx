ntx private development candidate: corresponding-source reconstruction

Verify SHA256SUMS in this directory before reconstruction. Keep this original
candidate directory unchanged. It contains no signer, games or user saves.
No public binary release is authorized by its creation.

Each .bundle contains public Git objects at its exact original HEAD. The adjacent
.shallow file MUST be installed before checkout/fsck: Git's bundle format does
not preserve shallow boundaries. An empty boundary means a complete repository.
Each exported repository has passed connectivity fsck with its recorded boundary.

In a new, capacity-admitted directory:
1. git clone --no-checkout /candidate/ntx.bundle ntx
   If ntx.shallow is nonempty, copy it to ntx/.git/shallow.
   git -C ntx checkout --detach HEAD
2. For each row of repositories.tsv, from the reconstructed ntx directory:
   git clone --no-checkout /candidate/NAME.bundle RELATIVE_PATH
   If NAME.shallow is nonempty, copy it to RELATIVE_PATH/.git/shallow.
   git -C RELATIVE_PATH checkout --detach HEAD
   git -C RELATIVE_PATH fsck --no-reflogs --connectivity-only
   These are independent repositories at the recorded gitlinks; no network
   submodule fetch is needed. Apply the maintained source patch:
   git -C .local/source/dolphin apply ../../../native/patches/0001-direct-adapter.patch
3. tar -xzf /candidate/cargo-vendor.tar.gz -C .local
   Add the following to .cargo/config.toml, retaining its existing settings:
   [source.crates-io]
   replace-with = "vendored-sources"
   [source.vendored-sources]
   directory = ".local/corresponding-source-vendor"
4. With the separately installed licensed SDK/NDK/toolchain identified by
   binding.json, set ANDROID_HOME and ANDROID_NDK_HOME as native/README.md explains.
   cargo xtask source-check
   cargo xtask configure-android
   cargo xtask build-android
   cargo xtask prepare-android
   cargo xtask package-android-unsigned

Rust 1.96.1 and the Android target are required; rust-toolchain.toml pins them.
The archive contains every locked Cargo package, selected native dependency
sources, unmodified Dolphin sources/resources, the maintained patch and all
ntx source/build scripts. Excluded native gitlinks are recorded but not needed
by this configuration. SDK/NDK/compiler executables are not redistributed here;
their observed versions/hashes and applicable runtime notices are retained.

Unsigned reproduction requires no owner's signer or private certificate receipt.
It produces ntx-unsigned.apk, with the same source/resource/ABI checks but no
signature claim. Independent builders may sign their own copy separately; that
cannot update an owner's installation. The continuing owner's package-android
command requires the retained signer, independent recovery and installed-candidate
certificate receipt and never generates a replacement key. Bit-identical APK reproduction is not claimed (signing,
timestamps and environment differ). Compare code/resources and recorded source
inputs independently. No gameplay, audio, save/reload or hardware result follows
from archive verification or build success.
N64 source reconstruction for candidates containing libntx_mupen64plus_next.so:
The preserved mupen-active-source.tar.gz contains the complete verified source
tree with the two maintained patches already applied, including dated notices.
Extract under .local/source. mupen-upstream-15bada85.tar.gz is the retained exact
original GitHub archive. native/mupen/source-files.sha256 records original Git
blob content (the archive's one Windows vcxproj CRLF expansion is normalized to
the pinned blob); patched-files.sha256 records the explicit overrides.
Run cargo xtask mupen-source-check and python3 native/mupen/check_boundary.py.
With the bound existing NDK30, run cargo xtask build-mupen, then the normal
package-android-unsigned route. No private signer is needed for source rebuild.
The ARM64/API28/GLES3/HLE/GLideN64 recipe and excluded optional plugins are in
xtask/src/mupen.rs; use the recorded tool hashes, source manifests and options.
GPLv3 and all selected component notices accompany this core combination.
