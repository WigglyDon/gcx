# ntx identity

A large green A cap in warm grey controller plastic: the GameCube sibling of
psx's blue Cross. Lowercase **ntx** is the product; **Machine Rhythm** is the maker.
The dark player uses the same quiet typography, centered column and tactile
controls, with green as ntx's primary accent. The first preview is marked Alpha.

The original SVG and Android vectors are source assets under MIT. Plastic/button
composition adapts the public MIT psx icon at revision
123e831e4afb6c7cec2d8e05a030e3cd82a72bba (icon.svg blob
b3f50733cfcc8bce7a780cb5f839b9bd285ac98a); attribution remains in LICENSE.
The A geometry, green cap and ntx identity are drawn here. No console logo,
startup screen, proprietary artwork or game cover is supplied. Themed icons use
the monochrome cutout; the ordinary icon retains the green cap. The adaptive
foreground stays within Android's safe circle. Store review remains separate.
